# Network Scanning using Nmap :

## Usage of Nmap :

1. Install Nmap

2. Find your local IP Range

2. Run: nmap -T4 -A -v 192.168.0.0/24
        ( -T4 = speed of the scan, -A = Aggressive scan , -v = verbose  )

3. This can result All the open ports, shows Host active or closed , service versions , operating systems,
     scripts results (about configurations and vulnerabilities)
